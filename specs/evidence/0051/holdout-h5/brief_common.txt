You are writing test items for a memory system. Each item is a short text that a person gave to an assistant app,
plus ONE candidate fact about that person, and the true answer to this question:

  GOLD QUESTION: In this text, does the USER, in their own words and in a part of the text that is theirs, state as
  currently true about themselves that <relation meaning>: <object>? A bare agreement with another speaker's wording

The thirteen relations and what each means:
  avoids_tool    the user avoids, has stopped using, or refuses to use a tool, app or service
  client_of      the user is a client or customer of a named business or professional
  has_diet       the user follows a diet or an eating rule
  has_pet        the user has a pet (the object is the animal or its name)
  health_state   the user has a health condition or is in a health state
  located_at     the user lives in or is based in a place
  measures       a measurement of the user (height, weight, a size, a reading)
  partner_of     the user's partner or spouse is the named person
  prefers        the user prefers something
  relative_of    the named person is a relative of the user
  uses_tool      the user uses a tool, app or service
  works_as       the user's job, role or profession
  works_on       a project, product or piece of work the user is working on

For every item give:
  "relation"      one of the thirteen names above
  "object"        the candidate value, a few words
  "text"          the whole text, exactly as it would appear, with its own line breaks
  "gold"          true or false: the answer to the GOLD QUESTION
  "value_source"  where the object's words appear in the text: "user", "other" (only another speaker), "both", or
                  "neither"
  "style"         a few words naming the kind of text (e.g. "support chat export")
  "note"          one short sentence saying why the gold is what it is

Write the texts the way real people and real tools produce them: realistic, varied, unpolished where that is real.
Do not explain the task inside the texts. Reply with ONE JSON array of objects and nothing else. Do not use any tools.
